# KALAN Interface

Designs HTML/CSS de référence pour l'application mobile.

## 📁 Contenu
- `html/` : Pages de référence pour chaque écran de l'app.
- `Avatars/` & `Badges_recompense/` : Assets graphiques utilisés dans les designs.

## 🎨 Utilisation
Ces fichiers servent de base visuelle pour le développement Flutter. Toute modification du design doit d'abord être validée ici avant d'être implémentée dans `kalan_app/`.
